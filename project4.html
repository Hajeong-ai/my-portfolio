Overleaf Re-design

AI-powered web-based LaTex editor

Overview

Overleaf is a Web-based LaTex editor that is used to create, collaborate, edit, and share documents. It is usuallly used for academic papers which contain high-level mathematical concepts and formulas.

Problem

The current Overleaf's suggestion, collaboration, and citation flow is confusing to users. Users wanted more clarity on parts of documents when they are collaborating with other users, incorporated suggestion flow, and less complex and non monotonous citation workflow.

User Interview

We conducted qualitative in-depth interview with 6 interviewees. Given a limited time-frame, we kept interviews relatively open-ended. Participants shared their screen and walked through how they use the platform.
Based on the discussion guide that has a set of questions we have asked, We focused on the questions regarding frequency of using platform, typical uses, challanegs with the platform, and compares with competitors.

Directed interview (5 parts)
Number of Interviewees: 6

User Persona

Through the interview, we were able to know the most users of Overleaf were highly-educated students, currently doing their master's or PhD, especially math heavy majors such as statistics, computer science, etc.

User Flow - Current

Before working on low-fidelity design, we started from understanding the current Overleaf's user flow. The current suggestion flow is scattered into 4 feature, which makes users confusing. For the collaboration, users need to manually assign responsibilities through third party tools, and communicate via Latex text.

User Flow - Expected

We've brainstormed new AI powered user flow for suggestion and collaboration workflow, and re-structured the information architecture to address the user pain points.

Turning Insights into Action From User Flow to Design Solution

1. AI Suggestion Feature

For solution, we divided AI suggestion into two groups of the suggestions.

First is simple grammer issues or code bugs, which is already debugged by Overleaf and opened to all of the users. We unified and streamlined how these two types of suggestions are displayed.

Second improvement covers more complex cases, such as writing improvements, and more complex debugging. For these, we've redesigned the Overleaf AI feature experiences so that the user can easily discover, review, and apply the improvements.

We went one step furtuer, where the current Overleaf have already enabled some AI features. However, at that moment, these features were seperate from the main editing flow. This means that users needed to integrate their edting in order to access the AI support.

In our redesigned AI feature, we've added a new tab on the left side of the editing. With this tab, users can quickly switch into the AI feature, chat with TexGPT (Overleaf's GPT), and incorporate AI suggestion seamlessly with just one click.

2. Collaboration

At the center of resolving collaboration issue is our task board, which connects conversations, comments, and real-time editing into one streamlined workflow. By commenting, collaborators can highlight a section and leave a comment by clicking the button that appears on the task board.

Another key feature of the task board is that it enables users to convert a chat into an action item by clicking the "Turn chat into a Task" button. Each task displays who created it, any comments added during editing, and the current staus of each task, whether it is processing, finished, or error.

Users can simply check it off when a task is done, and the status updates for the whole team to see, which can be checked on the history page.

While enhancing collaboration feature with task board, by showing exactly where each member is working, team can avoid conflicts.

Overall, our re-designed collawboration feature turns scattered conversations into organized and trackable ones.

Next Step & Feedbacks

1. If we had more time, we would improve the citation workflow as suggested by interviewees—not by manually inputting all citations as the current Overleaf does, but by integrating citation management tools into Overleaf.

2. After our presentation, a current Overleaf user suggested adding a feature that lets users control the degree of AI involvement when they are using a AI suggestion feature.
